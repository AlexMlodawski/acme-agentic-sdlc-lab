# Ten-minute demo guide

## Story

The message is: **A passing test or review recommendation is not yet a release decision.**

1. Show the portal and search for `ACME-1042`.
2. Open the contextual assistant and ask for status plus return guidance.
3. Explain the server-side provider boundary and local zero-secret profile.
4. Run the focused browser test.
5. Show the exact OpenAPI `priority` contract and correlated support-case result.
6. Open the evidence examples and contrast `pass`, `fail`, `not_completed`, and
   `not_asserted`.
7. Explain where Bob, watsonx Orchestrate Draft, and Instana can replace the
   local seams without changing the honesty boundary.

For a live agent-assisted extension, paste
`examples/prompts/01-bob-plan-only.md`, review the returned plan, then send the
exact continuation in `examples/prompts/02-go.md`. Use
`examples/prompts/03-release-review.md` only after a reviewable candidate exists.

## Claims you may make

- the local journey is reproducible and credential-free;
- the browser uses real portal and API processes;
- the integrated design keeps credentials server-side;
- the Draft package declares a read-only order tool;
- the evidence model refuses to convert missing proof into a pass.

## Claims you should not make

- that this is an official IBM reference architecture;
- that a local response came from watsonx Orchestrate;
- that a response proves an internal tool call or retrieval;
- that Draft means Live or production-ready;
- that a synthetic report is evidence from a live run.
